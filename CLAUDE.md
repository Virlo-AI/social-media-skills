# Virlo social media skills

Short-form video research skills (TikTok, Instagram Reels, YouTube Shorts) on Virlo's API or MCP.

- **Editing this repo:** read `AGENTS.md` first and follow it.
- **Running research here:** pick the skill that matches the ask and use `virlo-api` for every call. Follow its `references/house-rules.md`.

| The person asks | Skill |
|---|---|
| Set up who I am / my brand / my client | brand-brief |
| What's working / breaking out / going viral in a niche | niche-breakouts |
| What to jump on this week; trends; memes | trend-radar |
| Hooks, opening lines | hook-bank |
| Sounds about to blow up | sound-scout |
| Video ideas for me | content-ideas |
| Write scripts | script-writer |
| What's working at a place, near me, for local businesses | local-scout |
| What my competitors' best videos do | competitor-watch |
| Break down one creator | creator-teardown |
| Why this video went viral | video-teardown |
| Find or vet creators / influencers | creator-finder |
| What viewers ask for, in their words; comments | audience-voice |
| A brand's or keyword's Meta ads | ad-watch |
| How my posts or launch are doing | launch-monitor |
| Keep watching a niche and send me a weekly digest | niche-monitor |
| Raw access to any Virlo endpoint | virlo-api |
