# Examples gallery

Every report below came from a **real run on Nov 23 2026** against Virlo's live data (the weekly niche-monitor digest ran on Nov 22), using Claude Code with these skills. No data is mocked or edited for effect; the brand brief's input is a made-up test brand, and one interviewee's name is removed for her privacy.
- Each report names its prompt, shows every source video with a link, and ends with what the run cost.
- These are the same files the skills show in preview mode when there's no key yet.

Numbers are as of the run date, and short-form moves fast. Run a skill yourself for this week's picture.

## How to read these reports
- **"N× outlier"** is how many times more views a video got than its creator normally gets, judged on their other recent posts. It's the fair way to call something a breakout, because big accounts and small accounts are each measured against themselves.
- **VS** is Virlo's Virality Score, which compares a video with its creator's audience size. 18 is strong; 35 and up is exceptional.
- **Bought reach** (paid posts, or under 0.5% likes per view) is always listed separately and never counted as a breakout.
- **How every number is read** is in [method.md](../skills/virlo-api/references/method.md).
